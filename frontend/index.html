About the Project

Document Intake Assistant

Overview

The Personal Wishes Intake Assistant simplifies formal end-of-life and legacy planning into an intuitive, natural language interview. Instead of rigid multi-step web forms, it uses context-aware conversational extraction to assemble a real-time legal draft document.

Core Architecture

  • High-Speed LLM Inference: Powered by Groq’s LLaMA 3.1 8B Instant engine with structured JSON mode.
  • Self-Healing State Guard: Active heuristic validation ensures executor names, child counts, and post-mortem requests never contaminate gift records.
  • Full Session Persistence: Automatically cached to browser storage and committed to backend disk files so progress is never lost on refresh.

Important Notice

This system is intended for intake demonstrations and drafting assistance only. Generated drafts are fictional templates and do not constitute formal legal advice.
